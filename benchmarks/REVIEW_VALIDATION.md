# Stage routing and independent review — 2026-09-06

## Outcome

Independent routing is implemented, but this experiment does **not** justify
making independent review the default. The selected Qwen3 instruct model retained
all bad proposals. Qwen3.6 rejected them in its one completed trial, but timed out
in two of three trials at the fixed 90-second limit. Same-model DeepSeek review
had stronger evidence in these small controlled tests, with some good-edit loss
and one timeout. The UI default remains same-model review.

## Method (not human acceptance or end-to-end editor quality)

Twelve fixed **synthetic, agent-labelled** original/proposal pairs are in
`reviewer_cases.jsonl`: five useful corrections, four unwanted semantic/style
changes, and three technical-token violations. Labels are not sent to the model.
The same deterministic guards reject the three token violations before every
mode. The remaining nine identical proposals go to off/same/independent modes.
The proposals are constructed, **not generated by the named editor during this
experiment**; this measures reviewer filtering, not self-review bias or overall
pipeline improvement on naturally occurring thesis errors.

Three trials per mode; same/cross order alternates. Temperature 0.1, timeout 90 s,
one HTTP attempt per request and at most one explicit format-repair request.
Both models receive the same combined system instructions, source and proposals.
Failed trials are reported separately, never interpreted as rejecting bad edits.
Repeated trials reuse the same nine candidates and are not independent samples.

Editor/same-review label: `deepseek-ai/DeepSeek-V4-Flash`.
Endpoint: `https://api.siliconflow.cn/v1`. Protocol: `stage-models-v2`.
The final `stage-models-v3` also puts reviewer-proposal integrity checks inside
the existing single repair budget. Valid requests/results in the table are
unchanged; that addition affects only otherwise-invalid review responses.

The three bad semantic proposals (modality, negation and an invented actor) were
all retained by Qwen3-30B instruct in each trial. The fourth bad proposal is an
unnecessary synonym rewrite. Per-trial decisions, latency and token usage are

## Compatibility and safety

An earlier Qwen3.6 diagnostic returned HTTP 400 `System message must be at the
beginning`. Multiple system messages were combined without dropping any policy.
Those old-protocol results are excluded from the comparison above. The corpus
and labels were not changed after observing model results.

Model endpoint/key binding is validated before client construction. Different
endpoints never inherit the primary key implicitly. Stage keys are session-only
and excluded from saved stage profiles, cache identities and Run.json metadata.
The existing primary-key save behavior is unchanged.

New remote endpoints require HTTPS by default. Loopback HTTP is supported;
other HTTP requires explicit opt-in. To avoid breaking an already configured
gateway, the UI preserves HTTP permission only for the exact saved primary URL
and displays a warning. Changing that URL resets the opt-in. This compatibility
path is not encrypted transport and should be migrated to HTTPS where possible.
No existing user config or key was rewritten by this implementation.

`Run.json` records effective routes, parameters and actual request attempts with
token usage when supplied. Request statuses cover transport/completion-envelope
outcomes; semantic/decision validation is in the Excel records. Cached runs report
zero new requests. Stage request parameters and all model identities enter the
workflow cache key; chapter notes depend only on the understanding model identity.

## Reproduce

Final local checks: 54 offline/UI tests and 8 real Word tests pass. A complete
stage-routed Word run used Qwen3-30B instruct for understanding/review and DeepSeek
V4 Flash for editing: 3 actual API attempts, 2 edited sentences, saved revisions
verified, original source unchanged, and 0 additional attempts on cached fresh-
output replay. The synthetic Word smoke allows at most 8 actual HTTP attempts,
with up to two attempts per call and a 120-second timeout; these retry settings
are separate from the fixed reviewer-comparison settings above.

```powershell
python -m unittest test_pipeline_regressions test_p0 test_p1 test_stage_models test_review_compare test_stage_ui
python -m unittest test_p1_word
```

The first command includes headless Streamlit configuration/persistence tests;
the second needs real Microsoft Word. Paid checks read the existing key from
stdin, never the command line: `python -m benchmarks.review_compare` (up to 12
attempts), optionally `--reviewer-model Qwen/Qwen3.6-27B`.
`python -m benchmarks.stage_word_live --understanding-model Qwen/Qwen3-30B-A3B-Instruct-2507 --reviewer-model Qwen/Qwen3-30B-A3B-Instruct-2507`
checks actual stage routing, saved synthetic Word revisions and fresh-output cache
replay (up to 8 attempts). This Word check proves routing/persistence, not reviewer
quality. Both tools pin the official SiliconFlow endpoint and fixed synthetic data.
